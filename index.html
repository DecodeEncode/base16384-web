Encoding

Line breaks are for reading only. This page ignores them, but the reference tool does not, so download without them for that tool.

The reference tool writes UTF-16BE with a byte order mark, or without one when run with -n.

Decoding

Display

Equal byte patterns get equal colours, so repetition stands out.

Point at or tap a character to inspect it.

Benchmark

Measures how fast this browser encodes and decodes random data, next to its own base64 and hex. It runs in a background worker, so the page stays responsive. Results depend on the device and are not sent anywhere.

Alphabet

16384 characters, U+4E00 to U+8DFF, one for each 14-bit value, shown 256 at a time. Six end markers, U+3D01 to U+3D06, record the length of a short last group.

End markers

Point at or tap a character to inspect it.

Runs entirely in your browser; nothing you enter or drop is sent anywhere. base16384 is a notation, not encryption. This is an independent, unofficial tool, not affiliated with the authors of the base16384 format.
